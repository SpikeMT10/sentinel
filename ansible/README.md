# Ansible

Rezervované místo pro E1. Nejprve DEV-009/010: verzované schéma reportu a read-only preflight. Preflight nezakládá účty, neinstaluje balíčky, nerestartuje služby a nemění konfiguraci. Hosty pouze z autorizovaného inventáře. Konkrétní Ansible verze a závislosti připnout po výběru a ověření v izolované Debian VM.

Zatím zde není žádný spustitelný playbook ani role. Nejde o instalační návod.
