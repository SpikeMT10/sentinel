# Testy

Testy vzniknou postupně podle DEV-007, DEV-009–021 a AT-01–15 z MASTER 1.0. Pouze izolovaná VM a syntetická data.

- unit: parsování, validace schémat, negativní případy.
- integration: čistá a kontrolovaná použitá VM; opakovaná instalace, konflikty, izolace, výpadek.
- fixtures: syntetické inventáře, logy a reporty bez skutečných tajemství.

Automatizované testy ani integrační testy nebyly zatím implementovány nebo spuštěny. CI až po ověření repozitářových pravidel v DEV-004/005.
